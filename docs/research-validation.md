# 新版推演的验收记录

岳飞是本版用于验证逐轮博弈、史实对照和离线复算的案例。具体的材料和手工复算见 [岳飞案例核对](yue-fei-audit.md)。

## 怎样验收新题

把一句问题直接交给同一研究流程，使用真实的史料检索及模型。这里没有为任何一道新题添加专属规则，也没有将预先写好的答案作为模型输入。

验收时逐项检查实际历史决策与要改的决策是否一致、重要史料能否支持主张、各方是否确实从上一轮读取了状态，以及模型的指标是否回答提问。超出资料的假设和仅检验单项必要条件的结果分别按其范围解释。

| 测试话题 | 核对重点 |
| --- | --- |
| 1849 年普鲁士国王接受法兰克福议会授予的皇位 | 授冠、正式拒绝和各邦反应是否分时记录，改写是否由普鲁士国王的行动触发 |
| 1921 年英方放弃要求宣誓效忠君主 | 能否把谈判时的立场和后来签署的事实分开 |
| 1919 年美国政府接受洛奇保留条款 | 是否改变的是政府的立场，参议院的态度是否由可查约束推出 |
| 无名青铜时代城邦推迟继承法 | 标记为证据不足，并且没有概率 |

## 可复算与独立性

运行 `npm test` 可检查基础规则、日期分离、史实基线固定、作用于不同角色的逐轮行动、参数区间和概率约束。运行 `npm run simulate -- public/examples/yue-fei-1141.json` 可在离线环境复算已保存的分析包。

自动研究将明确标记为分岔后的证据从建模输入中隔离。这个隔离能通过程序测试。语言模型可能已经知道史实，因此这些试跑不能称为双盲评估。只通过了结构校验的模型需要继续审阅其原文与语义。

## 本轮结果

岳飞示例逐条对上了仓库中的原文摘录。按固定的史实条件复算，十月出使和十一月达成和议两项留出记录均与计算一致。两个分支从授权开始分开，朝廷协调和提交条款的内容各有一组单项翻转对照。浏览器已检查双时间线、行动依据和窄屏布局。

完整试跑获得了可复算的单项必要条件，也暴露了新题的上线风险。法兰克福题早期模型将议会或国王接受皇冠当成回应方的关键行动，偏离了奥地利是否承认的目标。英爱题的一组模型把取消宣誓同时保留相同宣誓要求，另一组没有将同一天签署的结果充分留出。凡尔赛题能指出三分之二门槛，仍缺少逐方票数与态度变化的可核对机制。无名城邦题返回证据不足。

根据这些误判，研究流程会固定原句的决策人、回应方和观察目标。历史角色的名称和头衔可通过已核对史料匹配。用法兰克福与凡尔赛两题保存的模型响应回放，已确认两组角色能够分别识别为普鲁士国王与奥地利、美国政府与参议院。单项必要条件会在网页中单独标注。本次还没有两道新题完成全局博弈的验收，版本保存在预览分支。
