# 岳飞案例的核对与复算

**问题**　继续授权岳飞参与对金议政，宋金议和议程会如何变化？

**观察窗**　绍兴十一年八月罢岳飞至次年八月。出使与缔约的观测集中在分岔后的第一个秋冬。模型只追踪从授权到外交议程的反应。

## 史料与留出观测

- 罢岳飞作为分岔点。枢密院任职和军马钱粮官的设置说明议政权限、朝廷分工与资源约束。七月旱情有记载，其是否改变此轮谈判仍待查。[《宋史》卷二十九](https://zh.wikisource.org/wiki/宋史/卷029)
- 岳飞传记录了此前对议和的异议。模型据此纳入提出复议的行为选项，是否提出仍由授权与行动规则决定。[《宋史》卷三百六十五](https://zh.wikisource.org/wiki/宋史/卷365)
- 宗弼传记载了金方在此前一轮中恢复旧疆的政策。模型据此把涉及边界的修订视为具有更高政治成本。具体偏好和效用排序仍是试验假设。[《金史》四库全书本卷七十七](https://zh.wikisource.org/wiki/金史_(四庫全書本)/卷077)
- 十月派遣稟议使和十一月立盟书写进独立的核对字段，执行规则的依据中没有这两条记录。作者知道这两条史实，本案例是人工构造并复核的示范。自动研究流程在模型冻结后才将后续摘录交给核对步骤。[《宋史》卷二十九](https://zh.wikisource.org/wiki/宋史/卷029)

## 手工复算

| 步骤 | 固定史实条件 | 改写条件 |
| --- | --- | --- |
| 1 | 取消议政授权 | 保留议政授权 |
| 2 | 岳飞不递交建议 | 岳飞递交复议建议 |
| 3 | 朝廷发出既有议程 | 朝廷协调能力或可用条款未知时，出使议程待定 |
| 4 | 金方按收到的议程继续，出使状态为是 | 需要观察使节送达的议程 |
| 5 | 模型中的和议状态为是 | 最终谈判结果保留为未知 |

在两个分支中使用同一组外部条件，逐对只变动一个参数：

| 条件 | 改写后走向 |
| --- | --- |
| 朝廷无法协调，其余条件允许提出履约保障 | 延续原议程 |
| 朝廷能够协调，有不改边界的履约方案 | 重启条款磋商 |
| 朝廷能够协调，只提出边界修订 | 出现议程分歧 |

这三组条件没有已知的历史频率。两处条件翻转可以复算，其概率仍待证据。

## 离线验证

```sh
npm run simulate -- public/examples/yue-fei-1141.json
```

预期固定基线核对出使和立盟书两项，分别在第 4、5 步落入模型的可比状态。完整复算输出 8 条轨迹，第一处分岔在第 1 步的议政授权，条件翻转涉及朝廷协调和提案内容。分析包保存冻结条件下的两条主轨迹及核对结果，导入后可从规则重新运行全部情景。
